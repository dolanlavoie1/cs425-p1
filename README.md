## Experience

This was a cool project to do because it was interesting to look directly at how a protocol works, and actually deal with sockets recieving and sending information. It was crazy to find out how simple this protocol is, and how easy it is to put in whatever information you want, even if most ISPs block port 25. The 3 layer split is there for testing purposes. If a function doesn't return anything, it is much harder to test than a function that has a return value. By making sure every function has a return value, we dont have to check for side effects that the function creates, and can just directly test what is returned. They also help because we can't have our tests actually send messages to the mail server, so we need to be able to test as much as possible without actually going onto the internet.
